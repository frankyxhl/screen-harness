## D Items

### D1 — Smart screen selection (fix camera misuse + multi-screen)

`start_recording` defaults `screen_index="0"` which on macOS AVFoundation is
often the FaceTime camera, not a display. On multi-monitor setups the right
display index is also non-deterministic. User wants the harness to auto-detect
which screen the target app is on, every launch probing and printing the device
list, and pick a screen device (never a camera). Routes to PRP SHR-2213.

### D2 — On-screen recording HUD (red dot + capture-region frame)

While recording, show a transparent always-on-top overlay: red REC dot + frame
around the capture region + countdown timer. Must NOT be recorded into
`final.mp4` (NSWindow `sharingType = .none` so AVFoundation/ScreenCaptureKit
skips it). PyObjC + NSPanel. Routes to PRP SHR-2214.

### D3 — Multi-agent skill packaging (Claude Skill + Copilot + Codex + agent.md)

Package as a Claude Code Skill (Anthropic Skills bundle) and emit equivalent
artifacts for GitHub Copilot (`.github/copilot-instructions.md`) and OpenAI
Codex (`AGENTS.md`), plus a top-level `agent.md` as lowest-common-denominator.
SKILL.md is the source of truth; the rest are generated by a sync script in
CI. Routes to PRP SHR-2215.
