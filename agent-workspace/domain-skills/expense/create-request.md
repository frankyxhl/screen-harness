# Expense: Create Request

Use this domain skill for expense-system SOP recordings.

## Durable Flow

1. Open the company back office.
2. Enter the expense system.
3. Click New Request.
4. Fill amount, expense type, reason, and attachments.
5. Submit the request.

## Style

- Use short action-first captions.
- Highlight primary buttons before the user clicks them.
- Redact employee names, account identifiers, receipt numbers, and internal URLs.
