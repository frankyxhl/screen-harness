## GitHub Copilot Chat opt-in

This file (`.github/copilot-instructions.md`) is read by GitHub Copilot Chat
**only** when the `github.copilot.chat.codeGeneration.useInstructionFiles`
setting is enabled. This setting is **per-user and opt-in** — it is not on by
default. Enable it in VS Code settings or at github.com to activate these
instructions.

```json
{
  "github.copilot.chat.codeGeneration.useInstructionFiles": true
}
```
